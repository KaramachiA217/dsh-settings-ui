## 1. 决策背景

原 D5=B「先建样本页再修」**已改判为 A「先修后建」**（决策方 2026-08-30 拍板，见 `20-plan.md` §1）。
理由：R1'–R5' 的参照物是已抽取的官方 CSS 真值，不依赖样本页即可逐条对照；先建样本页反而要在未对齐状态下反复返工。
**本单的定位是「对齐后的回归基线」**——固化成果、防止后续回退，而不是探索工具。

## 2. 需求（决策方原始要求，逐条不得遗漏）

1. **按组件类型分组展示官方示例**，至少覆盖：
   - 按钮：页面顶部工具栏 / 卡片内 / 表单底部 / 表格操作列 / 悬浮操作区
   - 浮窗类：Dialog / Modal、Popover、Tooltip、Dropdown、Toast、Drawer
   - 输入框、标签、提示条
2. **每个示例覆盖主要状态**：默认 / 悬停 / 聚焦 / 按下 / 禁用 / 加载
3. **每个样本旁标注样式来源**：组件名、关键类名、或设计 token
4. ~~**独立于业务路由**（`/ui-specimens`）~~ → **D7 改判**：dsh 客户端插件无路由能力（路由归官方 `dsh-web-app`），改为「设置页内独占分区 + 浮层」；**仅 localStorage 开发开关下注册，不污染生产代码**
5. **先出分组核对清单，再据此生成页面** ✅（`11-specimen-checklist.md` 已升 v2，样式来源全部回填）

## 4. 关键设计约束

- **开关隔离**：两个槽位的**注册**本身置于开发开关后（关闭时一个都不注册）；生产构建必须不可达（对应 DoD **V9**，已有自动化断言）
- **令牌失效自动暴露**（DoD **V10**）：样本应能直观看出某个 `--dsw-*` 是否失效（失效项高亮）
  - 实现提示：用 `getComputedStyle(document.documentElement).getPropertyValue(token)` 判空
- **必须用 kit 真实组件渲染**，禁止手写仿制品（否则样本页失去核对意义）
- 样式来源标注须精确到：组件名 / 类名 / token 名（对应 DoD **V10**）
