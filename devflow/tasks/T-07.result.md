## 2. 样本页结构与开关机制

**载体**：`lib/client.js` 单文件（kit 无构建步骤，源码即产物）。

| 组成 | 内容 |
|---|---|
| 样式 | `.sui-spec-*` 共 28 条，追加在 `CSS` 数组末尾；**全部语义 token，零裸值**（守住 V1） |
| 组件 | `SpecGroup` / `SpecCell` / `SpecMissing` / `ForceButton` / `TokenProbe` / `SpecSwatches` / `SpecTable` / `SpecimenPage` / `SpecimenOverlay` / `SpecimenToggle` |
| 开关 | `localStorage['dsh-settings-ui:specimen'] === '1'`，**默认关闭**；`specLocalStorage()` 优先读 `window.localStorage`（便于测试注入），回退裸全局，取不到一律按关闭处理 |

**双承载（D7）**：

| 承载 | 槽位 | id | 关键点 |
|---|---|---|---|
| 主 | `settings.section` | `dsh-settings-ui.ui-specimens`，order 9000 | 官方 `SettingsRoot` 用 `renderSlot(..., {only: active})`，**一次只渲染当前分区** → 点进去内容区只剩本页，体感即独立页 |
| 辅 | `shell.overlay` | `dsh-settings-ui.ui-specimens.overlay` | `.sui-fab` 把手（`pointer-events:auto`）+ `Panel`（拖动 / 最小化 / 记住位置 / 可调大小，持久化到 `dsh-settings-ui:specimen.panel`） |

**注册时机**：插件 `apply()` 期。因此开关改动**需刷新页面**才生效（UI 上已提示「刷新后生效」）。

**统计隔离**：样本页自身的两个注册项被 `isSpecimenId()` 排除，不计入统计卡的「通过 Kit 接入的插件数」。

## 4. V10 令牌失效高亮的实现与自测

**实现**：`TokenProbe` 在挂载时（`useEffect`）执行

```js
getComputedStyle(document.documentElement).getPropertyValue(name)
```

对 40 个关注令牌逐一取值，判空即判失效。判定逻辑：

| 类型 | 判据 | 展示 |
|---|---|---|
| 普通令牌 | 有值 = 符合预期 | 绿点 + 解析出的实值 |
| 预期缺失的令牌 | **空值** = 符合预期 | 灰点 + 「未定义」 |

「预期缺失」清单含 2 项自证项，用来证明体检**确实在检测**而不是恒绿：

- `--dsw-alias-state-business-secondary` —— kit 曾写错名，官方从未定义
- `--dsw-alias-label-error` —— **官方自身缺陷 O1**：官方两版 CSS 都在用，但从未定义

**自测结果**：SSR 环境下 `useEffect` 不执行，故自动化测试只覆盖「组件不崩 + 分组渲染」，**令牌解析值需在浏览器内目视**。页面顶部会直接列出每个令牌的实值，一眼可见哪些没解析出来。

## 5. 覆盖度自评

### 5.1 分组覆盖

| 组 | 清单要求 | 实际 | 说明 |
|---|---|---|---|
| A 按钮 | 5 个位置 + 尺寸 + 语义色 | ✅ 全覆盖 | 顶栏 / 卡内 / 表单底（两套）/ 表格列 / FAB；三语义 + 禁用 + 聚焦 + 悬停 + 加载 |
| B 浮窗 | 6 类 | 🟡 2 真实 + 4 占位 | Dialog / Toast 真实可触发；**Popover / Tooltip / Dropdown / Drawer 如实标注「未提供」** |
| C 输入 | 7 项 | 🟡 6 真实 + 1 占位 | 输入 / 文本域 / 下拉 / 复选 / 单选 / 开关齐全；**错误态标注未提供** |
| D 展示 | 8 项 | 🟡 7 真实 + 1 占位 | Badge / Banner / 空态 / Spinner / Dot / Tabs / List 齐全；**Skeleton 未提供** |
| E–I | 布局/配色/字体/圆角/响应式 | ✅ | 表格逐项对照官方值 + 实时色板（24 个令牌画成色块） |
| K 令牌体检 | — | ✅ | 40 个令牌运行时解析 |

### 5.2 状态矩阵

| 状态 | 实现 | 覆盖 |
|---|---|---|
| 默认 | 真实渲染 | ✅ |
| 悬停 | **强制态**（把 hover 的 token 写到行内样式） | ✅ |
| 聚焦 | **强制态**（`box-shadow:0 0 0 2px border-l3`） | ✅ |
| **按下** | **官方未定义 `:active`** | ➖ **不打勾**，页面已注明 |
| 禁用 | 真实 `disabled` 属性 | ✅ |
| 加载 | 按钮内嵌 `Spinner` | ✅ |

> 强制态是刻意的：真实 `:hover` / `:focus-visible` 无法静态截图，不钉住就没法逐项比对。

### 5.3 缺哪些、为什么

| 缺口 | 原因 | 处置 |
|---|---|---|
| 28px 行内按钮档 | 官方两档（36 通用 / 28 行内），kit 只有 36 | 页面标注，转 R10 候选 |
| 输入错误态 | 官方 `.inputInvalid` 依赖**自身未定义**的 `--dsw-alias-label-error`（O1） | 页面标注，转 R10 候选 |
| Badge 规格差一档 | 官方 `fs11/pad 1px 8` vs kit `fs10/pad 1px 6` | 页面标注，待决策方定跟哪套 |
| 图标体系 | rc.2 已无 `dsh-client-ui-primitives`，kit 用字符（`▾` `×`）代替 | 页面标注，随 R6' 处理 |
| Skeleton | kit 从未实现 | 页面标注 |

**原则：一律如实标注占位，不手写仿制品充当「官方示例」**（T-07 §5 硬要求）。
