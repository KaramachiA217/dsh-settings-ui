## 4. 关键约束

1. **只改样式与结构**，不动业务逻辑。
2. **优先用 rc.2 现行令牌**，其次 kit 自研变量兜底，**禁止新增裸值**。
3. kit 无构建步骤（`lib/client.js` 手写），改动需可直接运行验证。
4. 回滚点：`dsh-settings-ui` 是 git 仓，改前 commit；同时备份到 `devflow/backup/pre-<任务号>/`。
5. **验收命令由协调中枢亲自执行**，不采信执行方自述。
6. **无法自动判定的视觉差异一律列入人工核对**，禁止单方面标记「已修复」。
